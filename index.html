OVERVIEW

全体像：何を作るのか、いくらかかるのか

作るのは「録る → 文字にする → 貯める」が毎晩ひとりでに回る状態です。

会議は、自分の考え方も、商品のことも、お客さんとのやり取りも、その場で全部しゃべっています。ところが録画のまま置いておくと、結局あとから見返しません。そこで録画を文字にしてAIに読ませる形で残すところまでを自動にします。

3つのツールの役割

録る

Zoom / Google Meet

会議を録画します。Zoomはパソコンに保存する録画なら無料プランでも使えます。

文字にする

Grok（xAI）

音声を文字にします。使うのはGrok voice APIの文字起こし機能です。1時間あたり0.10ドル。

回す

Claude Code

パソコンの中の作業を代わりにやってくれるAIです。デスクトップアプリを使います。

作業の順番

  1. STEP1〜3は準備フォルダ・Zoomの保存先・Grokの鍵。ここだけ最初に1回やります

STEP 01

作業フォルダとClaude Codeを用意する

録画と文字起こしを置く場所を決めて、Claude Codeにその場所を教えます。

手順

1

「会議データ」フォルダを作る

MacならFinder、Windowsならエクスプローラーで、好きな場所に「会議データ」という名前のフォルダを作ります。デスクトップや書類フォルダの直下で大丈夫です。

例：書類 / 会議データ（この中に、あとで「文字起こし」フォルダが自動で作られます）
2

Claude Codeのデスクトップアプリを入れる

公式サイトからアプリをダウンロードしてインストールし、起動してサインインしたら「Code」タブを開きます。利用にはClaudeの有料プラン（Pro / Max / Team / Enterprise）が必要です。

Claude デスクトップアプリ ダウンロード Claude Code デスクトップ 公式ガイド
3

作業するフォルダに「会議データ」を選ぶ

最初のメッセージを送る前に、入力欄のまわりで作業フォルダ（Project folder）を選びます。ここで「会議データ」フォルダを指定すると、Claude Codeがこのフォルダの中を読んだり、ファイルを作ったりできるようになります。

ポイント：ふだん使っている書類フォルダ全体を選ばないでください。関係のないファイルまで読みに行くので、出てくる答えの精度が落ちます。この仕組み専用のフォルダを1つ用意するのが正解です。
4

許可の出し方（権限モード）を知っておく

Claude Codeは、ファイルを作ったり命令を実行したりする前に確認を出します。入力欄の横のモード切り替えで、確認の細かさを選べます。最初は既定の Manual（毎回確認）のままで進めて、毎回出てくる確認に「許可」を押していけば大丈夫です。

モードどうなるか
Manual毎回確認する（最初はこれ）
Accept editsファイルの編集は自動で進める
Plan調べるだけ。ファイルは変更しない
Auto安全チェック付きで全部自動
Codex（コーデックス／ChatGPTのAIエージェント機能）を使う方へ：ChatGPTのデスクトップアプリでも同じことができます。アプリを開いて「フォルダを開く（open a folder）」で「会議データ」を指定してください。以降の指示文（プロンプト）はそのまま使えます。ChatGPTデスクトップアプリ 公式ガイド

STEP 02

Zoomの録画がフォルダに入るようにする

録画の保存先を「会議データ」に変えておくと、あとは会議をするだけで素材が貯まります。

手順

1

保存先を「会議データ」に変える

パソコンのZoomアプリにサインインして、設定（Settings）→ レコーディング（Recording）を開きます。保存場所（Storage location）の変更（Change）を押して、STEP1で作った「会議データ」フォルダを選びます。

Zoom公式：パソコンに保存する録画の管理
注意：保存先をGoogleドライブやDropboxの同期フォルダ、外付けドライブにすると、録画の保存や変換に失敗することがあるとZoomが案内しています。パソコン内のフォルダを選んでください。
2

会議中に録画を始める

会議の画面の下にあるレコーディング（Record）を押して、このコンピューターにレコーディング（Record on this Computer）を選びます。無料プランでも使えます。自分がホストでない時は、ホストから録画の許可をもらってください。

マナー：録画する時は、最初に一言「録画させてください」と相手に許可を取ってください。
3

録り忘れを無くす（自動録画）

ZoomのWebサイトにログインして、設定 → 記録（Recording）→ 自動記録（Automatic recording）をオンにし、ローカルコンピューターに記録（Record on the local computer）を選びます（ローカル＝自分のパソコンの中、という意味です）。会議が始まった瞬間から自動で録画されます。無料プランの場合、自動録画はパソコン保存のみ使えます。

Zoom公式：自動録画の設定
4

会議が終わったら、変換が終わるまで待つ

会議を終了すると、Zoomが録画ファイルの変換を始めます。終わると保存フォルダが自動で開きます。中身はこうなります。

ファイル中身
video◯◯◯.mp4映像と音声
audio◯◯◯.m4a音声だけ（文字起こしはこれを使います）
chat.txt会議中のチャット
注意：変換の途中でパソコンを再起動したり、ノートパソコンの蓋を閉じたりすると、録画ファイルが壊れて戻せなくなることがあります。変換が終わるまで待ってください。

Google Meetを使っている場合

Google Meetの録画は、Googleドライブの「Meet Recordings（Google Meet）」フォルダに保存されます。そこからダウンロードして、「会議データ」フォルダに入れれば、この先の手順はまったく同じです。

  • 会議中に、右下の会議ツールアイコン →「録画」→「録画を開始」
  • 会議終了後、主催者のGoogleドライブ →「Meet Recordings」フォルダを開く
  • ファイルを選んで「その他」→「ダウンロード」
  • ダウンロードしたファイルを「会議データ」フォルダに入れる
先に確認：Google Meetの録画は、対応しているGoogle Workspaceのエディション（Business Standard 以上など）と、Google One 2TB以上のプランで使えます。無料のGoogleアカウントは対応一覧に入っていません。Google公式：Meetの録画

STEP 03

Grokの鍵（APIキー）を取る

文字起こしに使うのは、xAIのGrok voice APIです。鍵を取って、パソコンの中の隠しファイルに入れます。

APIキー（エーピーアイキー）は、外のサービスをAIから使うための、自分専用の暗証番号のようなものです。これを発行して、Claude Codeが読める場所に置いておきます。

手順

1

xAIのコンソールに登録する

xAIの管理画面（コンソール）にアクセスして、アカウントを作ります。

xAI コンソール xAI公式：はじめ方
2

APIキーを作る

コンソールのAPI Keysのページでキーを作成し、表示されたキーをコピーします。

注意：キーは作成した時にコピーして、安全な場所に保存してください。あとから同じキーをもう一度表示できるかは保証されていません。分からなくなったら、新しく作り直せば大丈夫です。
3

クレジットをチャージする

xAIのAPIは前払い式です。コンソールのBillingから支払い方法を登録して、クレジットを購入します。文字起こしは1時間あたり0.10ドルなので、最初は少額で十分です。

xAI公式：支払いとクレジット
補足：残高が減ったら自動で買い足す設定（Auto top-ups）もあります。チャージ額は5ドルから設定できます。
4

.envファイルを作ってもらう

.env（ドットエンブ）は、APIキーのような人に見せてはいけない情報を入れておくファイルです。Claude Codeにこう頼むと作ってくれます。

指示文1：.envファイルを作ってもらう 
xAIのAPIキーを取得したので、「会議データ」フォルダに.envファイルを作ってください。
XAI_API_KEY という項目を1行用意して、値は空のままにしておいてください。
5

.envを開いて、キーを貼り付ける

できあがった.envを開いて、XAI_API_KEY= の後ろに、コピーしておいたキーを貼り付けて保存します。.envは隠しファイルなので、そのままでは見えません。表示方法は下のとおりです。

パソコン隠しファイルの出し方
MacFinderで command + shift + .（ピリオド）を同時に押す。うまくいかない時は、メニューの「移動」→「フォルダへ移動」（command + shift + G）でフォルダのパスを直接入力する
Windows 11エクスプローラーの「表示」→「表示」→「非表示のアイテム」にチェックを入れる
Microsoft公式：隠しファイルの表示
キーの扱い：APIキーは暗証番号と同じです。チャットに貼らない・人に見せない・画面に映さないを徹底してください。漏れると、チャージした残高を他の人に使われてしまいます。

STEP 04

文字起こしを頼む

まずは1本だけ試します。ここがうまくいけば、あとは自動化するだけです。

録画が1本入っている状態で、Claude Codeにこう頼みます。日本語で頼むだけで、文字起こしをするためのプログラムをClaude Codeが自分で書いて動かしてくれます。

指示文2：録画を1本、文字にしてもらう 
「会議データ」フォルダにある直近のZoomの録画（音声ファイル）1本を、Grok voice APIの文字起こし機能で文字にして、「文字起こし」フォルダにテキストで保存してください。

条件:
- 使うモデルは grok-voice-transcribe-2.0、送信先は https://api.x.ai/v1/stt
- 言語は日本語（language=ja）、話者分けあり（diarize=true）
- APIキーは.envのXAI_API_KEYに入っています
- 1ファイル500MBを超える時は、音声を分割してから送ってください
- 終わったら、文字にしたファイル名をチャットで教えてください
足りない情報は私に質問してください。

やりとりの流れ

1

聞かれたことに答える

「どのファイルを使いますか」「保存先はここで良いですか」のように質問が来ます。答えていけば形になります。

2

実行の確認には「許可」を押す

プログラムを動かす前に確認が出ます。中身を見て「許可」を押してください。

3

できあがった文字起こしを開いて確認する

「文字起こし」フォルダにテキストができます。人の名前や商品名が崩れていないかだけ、ざっと目を通してください。崩れていてもSTEP5で直せます。

文字にしたら、すぐ使ってみる

貯めるだけでは意味がないので、その場でAIに聞いてみます。

指示文3：会議の決定事項をまとめてもらう 
「文字起こし」フォルダにある今日の会議のテキストを読んで、決まったことを3行でまとめてください。
あわせて、誰が何をやるかの宿題も箇条書きにしてください。
指示文4：過去の会議を検索する（貯まってから使う） 
「文字起こし」フォルダの中から、「{調べたいテーマ}」について話している会議を探して、
いつ・どの会議で・どんな結論になったかをまとめてください。
発言があった箇所は、録画の何分あたりかも書いてください。
使える理由：Grokの文字起こしは、話した時間（何分何秒か）と、話者の区別まで一緒に残せます。だから「あの会議で何て決めたっけ？」に、AIがそのまま答えられます。xAI公式：文字起こしAPIの仕様

STEP 05

スキルにして固定する

うまくいった流れを「スキル」にすると、次からは一言で同じ作業が動きます。

スキルは、作業の手順をAIに覚えさせたものです。一度作れば、毎回説明しなくても同じ流れで動いてくれます。作ったスキルはファイルとして残るので、チームのメンバーに渡すこともできます。

スキルクリエイターを使う

スキルを作るためのスキルがスキルクリエイター（skill-creator）です。日本語で頼むだけで作ってくれます。

1

使える状態か確認する

入力欄で / を打つと、使えるスキルの一覧が出ます。ここに skill-creator が無ければ、次の手順で追加します。

2

入っていなければ追加する

入力欄の横の + ボタン →Plugins →Add plugin を開くと、公式のプラグイン（機能を追加する部品）の一覧から追加できます。一覧から探せない時は、チャットに次の1行を送る方法もあります。

例：/plugin install skill-creator@claude-plugins-official
Claude Code公式：スキル
3

ここまでの流れをスキルにしてもらう

STEP4がうまくいった、同じチャットの続きで頼むのがコツです。それまでのやりとりを全部読んで、手順に落としてくれます。

指示文5：文字起こしをスキルにする 
スキルクリエイターを使って、ここまでのやり取りを全部参照して、業務をスキル化してください。

スキルの内容:
- 「会議データ」フォルダの中で、まだ文字起こししていない録画だけを見つける
- Grok voice APIの文字起こし機能で文字にして、「文字起こし」フォルダに保存する
- 終わったら、文字にしたファイル名をチャットで報告する
スキルの名前は「会議の文字起こし」にしてください。

作っている途中で、スキルの名前や、どんな時に使うかを聞かれます。答えていけば完成です。次からはチャットで「会議の文字起こしのスキルを使って」と言うだけで、同じ流れが動きます。

もう一段、精度を上げる（固有名詞の登録）

文字起こしで一番困るのは、人の名前や商品名が崩れることです。Grokの文字起こしには、先に覚えさせておきたい言葉を渡せる仕組み（keyterm）があります。最大100語まで、1語50文字までです。

指示文6：固有名詞を登録できるようにする 
このスキルに、私の名前・会社名・商品名・よく出るツール名を登録できるようにして、
文字起こしのたびにGrokへ渡すようにしてください（keytermパラメータ）。
登録する言葉は、スキルの中の分かりやすい場所に一覧で書いておいてください。

そのまま使えるスキル（配布用）

ここまでの流れを、誰でもそのまま使える形にしたものが下です。丸ごとコピーして、Claude Codeのチャットに貼り付けると、この手順書どおりのスキルを作ってくれます。個人の設定（保存先・固有名詞）は、最初に使う時に聞かれるので、答えるだけで動きます。

指示文7：配布用スキル（コピーして貼るだけ） 
スキルクリエイターを使って、下の内容のスキルを作ってください。名前は「会議の文字起こし」です。

## このスキルがやること
会議の録画（音声ファイル）を、Grok voice APIで文字にして、指定のフォルダにテキストで保存し、結果をチャットで報告する。

## 最初に使う時に、ユーザーへ質問すること
1. 録画が入っているフォルダはどこか（例：会議データ）
2. 文字起こしを保存するフォルダはどこか（例：会議データ/文字起こし）
3. 正しく書き起こしたい固有名詞（本人の名前・会社名・商品名・よく出るツール名。最大100語）
4. 議事録の要約も一緒に作るかどうか
答えてもらった内容は、スキルの設定としてファイルに保存し、次回からは質問しない。

## 毎回の処理手順
1. 録画フォルダの音声ファイル（.m4a / .mp3 / .wav / .mp4）を新しい順に見る
2. 同じ名前のテキストが文字起こしフォルダに無いものだけを対象にする（処理済みは飛ばす）
3. 1件ずつ、xAIの文字起こしAPIへ送る
   - 送信先: https://api.x.ai/v1/stt
   - モデル: grok-voice-transcribe-2.0
   - language=ja、diarize=true、登録済みの固有名詞をkeytermで渡す
   - APIキーは.envのXAI_API_KEYから読む（キーの値はチャットに出力しない）
   - 1ファイル500MBを超える場合は、音声を分割して送り、結果をつなげる
4. 結果を「YYYY-MM-DD_会議名.txt」の形で文字起こしフォルダに保存する
   - 1行ごとに、話した時間（開始からの経過）と話者番号を付ける
5. 要約を作る設定なら、同じ名前で「_要約.md」も作る（決定事項・宿題・次回までの確認事項）
6. 最後に、処理したファイル名と件数、失敗があればその理由をチャットで報告する

## 注意
- APIキーとその値は、チャット・ログ・ファイル名に絶対に書かない
- 失敗したファイルがあっても止まらず、残りを処理してから最後にまとめて報告する
- 同じファイルを二重に処理しない
スキルの置き場所：作ったスキルは、パソコンの中にフォルダとして保存されます。場所が分からなくなったら、チャットで「さっき作ったスキルはどこに保存されましたか？」と聞けば教えてくれます。チームに渡す時は、そのフォルダごと共有すれば同じ仕組みが使えます。

STEP 06

毎日自動で動かす

Claude Codeの「ルーティン」に登録すると、毎晩ひとりでに文字起こしが進みます。

手順

1

ルーティンを開く

Claude Codeのデスクトップアプリで、左のサイドバーのRoutines（ルーティン）を開きます。見当たらない時は、サイドバーのMoreの中にあります。

2

「New routine」→「Local」を選ぶ

Local＝ローカル（自分のパソコンの中で動かす方法）を選びます。もう一つのCloud（クラウド）はネット上で動くため、パソコンの中のファイルを読めません。今回は必ずLocalのほうを選んでください。

Claude Code公式：ローカルの定期実行
3

中身を入れる

入力欄入れるもの
Name（名前）会議の文字起こし
Description（説明）未処理の録画を毎晩まとめて文字にする
Instructions（やってほしいこと）下の指示文8をそのまま貼る
フォルダ「会議データ」（指示欄の下で選びます。必須です）
Schedule（いつ）Daily（毎日）＋ 時刻。深夜2時など、パソコンを使っていない時間がおすすめ

保存したら「Run now」で1回試す

保存後、詳細ページのRun now（今すぐ実行）で1回動かします。実行の途中で確認が出たらalways allow（常に許可）を選んでおくと、次からは止まらずに最後まで動きます。

ポイント：ここで「常に許可」を選んでおかないと、夜中の実行が確認待ちで止まったままになります。必ず1回手で動かして、確認に答えておいてください。
5

パソコンがスリープしない設定にする

ルーティンはアプリが起動していて、パソコンが起きている間だけ動きます。設定のDesktop app → GeneralにあるKeep computer awake（パソコンをスリープさせない）をオンにしてください。

注意：ノートパソコンは、蓋を閉じるとこの設定でもスリープします。夜のあいだは蓋を開けたままにしておいてください。もし実行できない日があっても、次にパソコンを開いた時に直近の1回分だけまとめて実行されます（7日以内）。

動き出したあとの見かた

  • 実行されるとパソコンに通知が届く
  • サイドバーの「Scheduled」に、その回のやりとりが残る（あとから中身を確認できる）
  • 時間ややることは、詳細ページの「Edit」でいつでも変更できる
  • 止めたい時は「Status」を Paused（一時停止）にする
すぐ文字にしたい時は：会議が終わった直後にチャットで「会議の文字起こしのスキルを使って」と言えばその場で動きます。普段はルーティンに任せておけば大丈夫です。
